NAMEFINDER / 07

Your Ubisoft session

Automated lookups can lead to restrictions. This mode has not been tested with a live authenticated account.

  1. Sign in on the official Ubisoft account page.
  2. Press F12, open Network, then refresh.
  3. Select a request to public-ubiservices.ubi.com.
  4. Under Request Headers, copy Authorization, starting with Ubi_v1 t=.
  5. Paste it into this app. Copy Ubi-SessionId too if present.

Treat the ticket like a password. Never share it. This app keeps it in memory and sends it only to Ubisoft for read-only profile checks.

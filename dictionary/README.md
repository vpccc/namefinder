# Bundled English words

`english.txt` is a modified, deduplicated subset of lowercase, ASCII, 3–5-letter entries from the standard SCOWL Hunspell British (-ise) and American dictionaries, release 2026.02.25. Hunspell flags were removed; capitalized entries, punctuation and other lengths were excluded. Affix rules were not expanded, so this is not exhaustive. It is a spelling dictionary, not a list of definitions or a ranking of desirable usernames.

Source: https://github.com/en-wl/wordlist/releases/tag/rel-2026.02.25
